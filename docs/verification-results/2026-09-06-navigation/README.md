# ホバーと目次追従の検証

対象はTailwind移行後の追加修正。目次だけ下線を伸ばし、その他のAppLinkは400msでopacityを1から0.8へ変える。目次の選択はスクロール位置に追従する。関連リンク欄の無効なnoneクラスはhiddenへ修正した。

- build（型検査含む）・lint：成功。
- 関連リンク欄：375・1043・1279pxで非表示、1280・1440pxで本文の右列に表示することをブラウザーで確認。
- ChromiumのE2E：12件成功。
- WebKitのE2E：初回11件成功、目次ホバー1件失敗。自動hover操作がscrollIntoViewを行い、閲覧位置が変わることを座標取得で確認した。選択中のホバー色のテストは読み込み演出終了後の実ポインター移動へ変更し、選択属性の維持も検証するようにした。
- 修正後のWebKit：ホバー、スクロール追従、目次選択色の3件が成功。[再検証結果](e2e-webkit-targeted.json)

先頭・末尾・上下のスクロール、通常スクロールでURLが変わらないこと、目次だけの下線、本文リンクの400msフェード、選択中の緑色を確認した。既存の初回表示・再訪・ハッシュ移動・履歴・reduce・印刷・幅別表示も上記E2Eに含む。

プレビューはローカルの4180番を使用。今回の追加修正ではモバイルエミュレーション、Firefox、Lighthouse、コントラストを再検証していない。これらの過去の結果を今回の実測として扱わない。
