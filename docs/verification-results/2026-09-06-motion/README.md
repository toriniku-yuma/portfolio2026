# ドット・フェード・共通リンクの改修

2026-09-06、ローカル本番プレビュー http://127.0.0.1:4180/ 。

## 変更と原因

以前はカードがopacity:1で描画された後、初回進入アニメーションによって0へ戻っていた。初期opacity:0とdata-seenによる表示保持を導入し、最初から最後まで0→1の方向に統一した。長文の途中へ移動した場合にも表示されるよう、観測対象はh2からカードへ変更した。開始位置は画面下端から高さの25％・最大200px内側を維持。

アスタリスク背景のドットは横移動し、停止・再開ボタンとreduceに対応。トップの文字は上から下へ順にフェードする。内部リンクはsmooth移動し、reduce時は即時移動する。

AppLinkとlink.recipe.tsで全リンクを共通化。ナビ・ブランド・フッター・関連リンク・Markdown本文リンクすべてに、右へ伸びる下線のhover/focus演出を適用。複数行は背景下線で扱う。

- 初期opacity:0、進入後0→1、再訪時の演出回数・DOM保持、smooth移動の非即時性、共通リンクと実際の下線幅、背景停止、focusin・検索時の表示を検証。
- 遅延画像のテストは読み込み完了前に判定していたため、完了を待つチェックへ修正した。
- 375px / 1440pxのトップを画像確認。保存した全体画像はreduce設定でレイアウト確認用に撮影。通常時の動きはE2Eで確認。
- print.pdf、contrast.json、bundle.jsonを更新。Lighthouse再計測は実施していない。
