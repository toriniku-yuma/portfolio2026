# UI・アクセシビリティ仕様

名前「Kawakami Shunki」と「川上駿季」をヒーローに大きく表示する。年号はブランドに含めない。黒と明るい緑、余白、細い罫線を中心に構成する。

## 情報構成

名前 → 目次・プロフィール・これまでの歩み・できること・作例・連絡先 → フッター。

全件表示ボタン、表示件数、表示済み・検索の案内、モック注意書き、「興味のあるところから、気軽にご覧ください。」は表示しない。

## 採用デザイン

B / Timelineを採用。左の細い緑のラインと番号で経歴の連続性を表す。比較UI・他の案・切り替え処理は削除する。
トップには角括弧と緑の8本スポークのアスタリスク、小さな十字とTHINK. BUILD. REPEAT.を配置する。名前は維持する。

共通値はsrc/styles/index.cssの@theme、各要素のスタイルは対応するTSX内のTailwindクラスで管理する。余白は4px単位のTailwind spacingを使う。

最大幅1480px。1024px未満は1列、1024px以上は目次と本文、1280px以上は外部リンクを加えた3列。外部リンク欄の見出しは「外部リンク」。1280px未満ではフッターの罫線下・署名の上に同じリンクを横並びで表示し、狭い幅では折り返す。本文のリンクも残す。目次は折り返す。本文とカードはmin-width:0、長い語は折り返し、表・コードは名前付き領域内だけ横スクロールする。画像は16:9の領域内にcontainで収める。

## 意味付けと操作

- h1は1つ、本文セクションh2、Markdownはh3以下。ランドマークと本文スキップリンクを設ける。
- 移動はa、アイコンはlucide-reactを使用し、装飾アイコンはaria-hidden。
- 技術名と数値はcontent/03-skills.mdのskills配列から読み、role=meterにmin/max/nowと名前を付ける。
- Tab/Shift+Tab/Enter/Spaceの標準操作を維持し、focus-visibleを明示する。
- 全本文を最初からDOMに置く。aria-liveで本文を読み上げさせない。reduce時は全ての動きを抑制する。
- 印刷は白地と濃い文字、装飾・ナビを除去。JavaScript無効時はnoscriptを表示する。

文字のコントラスト目標は4.5:1、フォーカスは3:1。実測・未確認範囲は[検証記録](verification-results/README.md)を参照。

## モーションとリンクの追加仕様

- アスタリスクの背面にドットグリッドを復元し、横へ流す。停止ボタンは置かず、reduceに対応。
- 読み込み時はトップの文字を上から下へフェードし、順に表示する。
- カードは初期opacity:0から表示する。見えている状態から0へ戻さない。
- 内部リンクはsmooth scroll、reduce時は即時。全リンクをAppLinkで共通化する。目次だけ下線が右へ伸びる演出を残し、その他のリンクは400msでopacityを1→0.8へ緩やかに変化させる。hover/focus-visibleの双方に適用する。
- 目次の選択項目はスクロール位置に追従する。カード上端がフェード開始線（画面上端から65％）に達した最後の項目を選択し、ページ末尾では最後の項目を選択する。先頭ではプロフィールを選択し、次のカードがフェード開始線に達するまで維持する。選択色はホバー時も緑を維持する。

目次にも読み込み時のフェードを付ける。選択中の項目はhover時も緑色。トップ下に罫線を加え、本文との空白は32px。ヒーローの上下余白はモバイル32px、PC48pxへ縮小する。

目次の現在位置表示は1024px以上のみ。1024px未満（SP・タブレットの上部目次）では全項目を未選択とし、aria-currentも付けない。幅の変更時にも即座に更新する。
